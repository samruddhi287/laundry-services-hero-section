
# Laundry Services Hero Section

## Project Description
A responsive laundry services landing page created using HTML5 and CSS3.

## Features
- Navigation bar with Logo, Home, Services, About Us and Contact Us
- Hero section with heading and description
- Laundry-related image
- Book a Service Today button
- Inline-block layout without Flexbox
- Viewport-based sizing
- Button hover effect
- Responsive styling

## Technologies Used
- HTML5
- CSS3

## Files
- index.html
- style.css
- Readme.md

## How to Run
1. Keep all three files in the same folder.
2. Open index.html in a web browser.
3. Ensure you have an internet connection to load the image.
